The `[actions]` `ARTIFACTSV4_SECRET` configuration directive will automatically get added and initialized from `[oauth]` `JWT_SECRET`. This requires forgejo to write the configuration file. If this fails with an error like `Unable to load settings from config: save actions.ARTIFACTSV4_SECRET failed: failed to save "/etc/forgejo/app.ini": open /etc/forgejo/app.ini: permission denied`, the administrator should add the new configuration directive by other means. See the _Key Management and Rotation_ section in the Forgejo Administrator Guide for details on how to seamlessly change this secret.
